# 이화(梨花)에 지는 달 : 대치동 환생록

현대 대치동 육성 시뮬레이션 + 임진왜란 전생 비주얼 노벨 로맨스.
모바일 WebView 패키징용 **단일 HTML 파일** (`index.html`, 외부 의존성은 Google Fonts뿐이며 없어도 시스템 폰트로 동작).

## 실행
`index.html`을 브라우저에서 열거나, 하이브리드 앱(WebView)의 로컬 에셋으로 넣으면 바로 플레이할 수 있습니다.

## 구성
- **주간 5슬롯 스케줄**: 평일 오후 / 평일 야간 / 주말 오전·오후·저녁, 총 30턴(1학년 3월 ~ 3학년 12월)
- **리소스**: 체력(0 → 강제 병결), 스트레스(100 → 슬럼프), 용돈
- **스탯**: 학업, 예술, 감수성, 화술, 매력, 전생 감응력, 근력
- **인물 6인**: 이안 · 강무진 · 류시현 · 윤서하 · 한태준 · 김사야(서브, 공략 불가)
- **밤의 꿈**: 호감도와 전생 감응력 조건을 넘으면 전생 VN 에피소드 해금 (총 22편, 히든 포함)
- **엔딩**: 커리어 1순위 판정 → 진/노멀/자아실현 엔딩 → 크레딧 → 사야 에필로그(부고 / 히든 생존 편지)
- **저장**: 매 턴 자동 저장 + 수동 슬롯 3개, 전생 기억·엔딩 컬렉션은 회차를 넘어 영구 보존

## 이미지 에셋 교체
스크립트 상단의 `ASSETS` 객체에 경로를 넣으면 그라데이션 실루엣/배경 대신 이미지가 출력됩니다.
```js
ASSETS.chars.ian = 'img/ian.png';          // 현생 스탠딩
ASSETS.charsPast.ian = 'img/ian_past.png'; // 전생(밤) 스탠딩
ASSETS.bgs.library = 'img/bg_library.jpg'; // 배경 (키는 BGS 참고)
```
