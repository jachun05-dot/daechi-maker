# 연애 파트 — 시스템 틀 (확정 · 아직 코드 반영 전)

인물 플롯은 이 틀 위에 얹는다. 새 인물을 쓸 때는 [_TEMPLATE.md](_TEMPLATE.md)를 복사해 채우고, 채운 예시는 [taejun.md](taejun.md)를 본다.
인물 설정 원본은 [../CHARACTERS.md](../CHARACTERS.md) — 한태준만 확정, 나머지는 플롯을 다시 쓰는 중.

## 한 줄 방향
숫자를 쌓는 연애 → **그 사람을 이해하는 연애**

## 관계 단계
**첫 만남 → 아는 사이 → 친구 → 썸 → 연인**
- 단계는 **장면(메인 이벤트)으로만** 오른다. 호감은 다음 장면이 열리는 조건
- 화면에는 단계 이름 + 하트 5칸만. 숫자는 숨긴다

## 두 가지 마음
| | 오르는 방법 | 쓰임 |
|---|---|---|
| ♥ 호감 | 자주 보기 — 출몰 · 톡 · 약속 · 데이트 | 단계가 열리는 조건 · 노멀 엔딩 |
| 🔑 속마음 | 그 사람의 상처를 정확히 건드리는 선택 (인물당 3~4개) | 진 엔딩은 열쇠 전부 |

- 선택지는 세 갈래로 쓴다: **열쇠**(🔑 열림) / **다정한 오답**(♥만 오름) / **잠금**(그 열쇠가 이번 회차에 닫힘)
- 일부 열쇠 선택지는 **그 사람 전생 꿈을 본 뒤에만** 보인다 → 감응 스탯과 연애가 이어진다

## 데이트 (약속 확장)
- 약속 수락 → 장소 고르기 (그 사람이 좋아하는 곳에 ★) → 장면 한 컷 + **대성공 / 성공 / 실수** 판정
- 판정은 평일과 같은 방식: 그 사람이 좋아하는 능력치 vs 난이도, 컨디션·스타일 보정. 실수도 귀여운 장면
- **취향은 발견형** — 좋아하는 능력치·장소, 싫어하는 것이 도감에 하나씩 채워진다
- 연애는 주말 칸과 용돈을 쓴다 → 꿈과 시간을 다툰다

## 소문 · 질투
- 학교 안 인물과 자주 붙어 다니면 **소문**이 쌓인다 (지유가 전해 줌)
- 일정 이상이면 **질투 장면** — 해명 / 솔직히 / 모른 척. 자동 감점은 없앤다
- 학교 밖 인물은 소문 대신 인물마다 고유한 질투 반응

## 고백
- 썸 + 열쇠 2개 이상 → **그 사람이 먼저 고백** (2학년 겨울 ~ 3학년 가을)
- **받기 / 기다려 달라기(한 번) / 거절**
- 받으면 연인 — 다른 썸은 정리 장면, 3학년 연인 이벤트(수능 vs 연애 · 기념일 · 싸움과 화해), 소홀하면 이별 위기
- **썸은 여러 명과 동시에, 연인은 한 명**
- 고백을 안 받았으면 3학년 겨울 **마지막 선택**은 지금처럼

## 엔딩 갈래 (인물마다)
| 엔딩 | 조건 |
|---|---|
| 진 | 꿈 이룸 + 열쇠 전부 + 연인(또는 마지막 선택에서 받아들여짐) |
| 노멀 | 이어졌지만 열쇠가 모자라거나 꿈을 놓침 |
| 엇갈림 | 썸까지 갔는데 고백을 놓침 — "그때 말할걸" |
| 차임 | 마지막 선택에서 호감 부족 |
| 히든 | 진 엔딩 + 인물별 특수 조건 (후일담) |

- 커리어 엔딩과 합쳐 후일담 한 줄을 붙인다
- 이현 엔딩 · 그랜드 엔딩(이안) · 프롤로그의 손 규칙은 GAME_DESIGN.md 그대로
